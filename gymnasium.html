Gymnasium 快速上手指南

强化学习生态一般分两层：环境接口层（Gymnasium / PettingZoo）和算法/训练层（SB3 / CleanRL / Tianshou / RLlib / TorchRL 等）。

Gymnasium 不是算法库，是“环境接口标准”——它负责 reset / step / observation / reward / done，不负责 PPO/DQN。

几乎所有的开源强化学习框架，都支持 Gymnasium。我们用一篇文章，快速入门 Gymnasium。一步步跟着做，出问题丢给 Agent 帮你解释，帮你解决。也可以参考我的代码。

第 0 步：建环境（一次就好） 

cd rl-env
uv venv .venv
source rl-env/.venv/bin/activate
uv pip install "gymnasium[classic-control]"

后面再按需装：

uv pip install "gymnasium[box2d]"      # LunarLander
uv pip install "gymnasium[mujoco]"     # 连续控制
uv pip install stable-baselines3       # 后面训练用

第 1 步：跑通“随机智能体” 

import gymnasium as gym

env = gym.make("CartPole-v1", render_mode="human")
obs, info = env.reset(seed=42)

done = False
total_reward = 0

while not done:
    action = env.action_space.sample()  # 随机动作
    obs, reward, terminated, truncated, info = env.step(action)
    total_reward += reward
    done = terminated or truncated

print("随机策略总回报:", total_reward)
env.close()

✅ 目标：看到小车乱动、杆子倒下 ✅ 记住这 5 个返回值：

obs, reward, terminated, truncated, info = env.step(action)

terminated = 任务失败/成功 truncated = 超时（不是算法概念，是人为截断）

第 2 步：搞懂 Space 

import gymnasium as gym

env = gym.make("CartPole-v1")

print("observation_space:", env.observation_space)
print("action_space:", env.action_space)

print("采样观测:", env.observation_space.sample())
print("采样动作:", env.action_space.sample())

你要能回答：

  • CartPole 观测是几维？（4 维）
  • 动作是离散还是连续？（离散 0/1）
  • Pendulum 为什么不一样？（连续动作）

再跑：

import gymnasium as gym
env = gym.make("Pendulum-v1")
print(env.observation_space)
print(env.action_space)

第 3 步：写“规则策略”，不是学习

CartPole 启发式规则：

import gymnasium as gym

env = gym.make("CartPole-v1", render_mode="human")
obs, _ = env.reset()

done = False
while not done:
    # obs = [x, x_dot, theta, theta_dot]
    _, _, theta, _ = obs
    action = 0 if theta < 0 else 1
    obs, reward, terminated, truncated, _ = env.step(action)
    done = terminated or truncated

env.close()

✅ 目标： 你开始“用观测决定动作”，这就是 policy 的雏形

第 4 步：用手写 Q-Learning（离散环境）

先用离散环境：Taxi / FrozenLake

pip install "gymnasium[toy-text]"

文件：taxi_qlearning.py

  1. 建 Q 表：Q[s, a]
  2. epsilon-greedy 选动作
  3. Q[s,a] += lr * (r + gamma*max(Q[s']) - Q[s,a])
  4. 跑 10000 步
  5. 看回报从 0 涨到稳定

这一步非常关键： 你会真正理解 reward / episode / discount / exploration

第 6 步：用 Stable-Baselines3 训练 CartPole

文件：cartpole_sb3_ppo.py

import gymnasium as gym
from stable_baselines3 import PPO

print("🚀 开始训练...")
env = gym.make("CartPole-v1")
model = PPO("MlpPolicy", env, verbose=1)
model.learn(total_timesteps=20_000)
print("\n✅ 训练完成！")

print("\n🎮 开始测试...")
test_env = gym.make("CartPole-v1", render_mode="human")

for test_ep in range(3):
    obs, _ = test_env.reset()
    done = False
    total_reward = 0

    print(f"\n--- Test Episode {test_ep + 1} ---")
    while not done:
        action, _ = model.predict(obs, deterministic=True)
        obs, reward, terminated, truncated, _ = test_env.step(action)
        total_reward += reward
        done = terminated or truncated

    print(f"Total Reward: {total_reward}")

env.close()

第 7 步：用 Stable-Baselines3 训练 Pendulum

详见 pendulum，总共 4 节课：环境解剖 → SAC 训练 → 手写 DDPG → 可视化演示

✅ 到这里你已经“跑通 RL 全流程”了

第 8 步：学 Wrapper（很重要）

常见 Wrapper：

  • Monitor：记录回报
  • RecordVideo：录视频
  • NormalizeObservation / NormalizeReward
  • FrameStack：图像任务

例子：

import gymnasium as gym
from gymnasium.wrappers import RecordVideo

env = gym.make("CartPole-v1", render_mode="rgb_array")
env = RecordVideo(env, video_folder="videos", episode_trigger=lambda x: True)

obs, _ = env.reset()
done = False
while not done:
    obs, reward, terminated, truncated, _ = env.step(env.action_space.sample())
    done = terminated or truncated

env.close()

第 9 步：写自己的 Gymnasium 环境（入门完成）

最小自定义环境：

import gymnasium as gym
from gymnasium import spaces
import numpy as np

class MyGridEnv(gym.Env):
    def __init__(self):
        self.action_space = spaces.Discrete(2)  # 0=左, 1=右
        self.observation_space = spaces.Box(0, 10, (1,), np.float32)

    def reset(self, seed=None, options=None):
        super().reset(seed=seed)
        self.x = 0
        return np.array([self.x], dtype=np.float32), {}

    def step(self, action):
        self.x += 1 if action == 1 else -1
        self.x = int(np.clip(self.x, 0, 10))

        reward = 1.0 if self.x == 10 else 0.0
        terminated = self.x == 10
        truncated = False
        return np.array([self.x], dtype=np.float32), reward, terminated, truncated, {}

# 注册
gym.register("MyGrid-v0", entry_point=MyGridEnv)

然后：

env = gym.make("MyGrid-v0")

✅ 能做到这一步 = Gymnasium 入门完成

延伸阅读： 1. 官方文档 Make your own custom environment. 2. 官方文档 Create a Custom Environment.

推荐练习顺序（别跳）

  1. CartPole 随机
  2. CartPole 规则策略
  3. Taxi / FrozenLake + Q-Learning
  4. CartPole + PPO（SB3）
  5. Pendulum + SAC（连续动作）
  6. Wrapper
  7. 自定义环境
  8. gym.make_vec 多环境并行
  9. CleanRL 读 PPO 源码
