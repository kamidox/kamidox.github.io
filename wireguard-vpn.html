使用 wireguard 创建私有 VPN 服务器

写在前面¶

本文档记录了在 ubuntu 22.04 上安装 wireguard VPN 服务器的过程，并在 MacOS 上使用。

之前使用 strongswan 搭建过 IPsec VPN 服务器，配置过程比较复杂，且在 MacOS 上使用时经常出现连接问题。相比之下，wireguard 的配置过程非常简单，且性能优越。

前置条件¶

  1. 你必须有一台海外的服务器，且有 root 权限。我选择的是 AWS 新加坡的服务 EC2 服务器。
  2. 服务器的防火墙允许 UDP 端口 51820 的流量通过。

服务器端操作¶

安装 WireGuard¶

sudo apt update
sudo apt install wireguard -y

生成密钥对¶

wg genkey | sudo tee /etc/wireguard/private.key
sudo chmod go= /etc/wireguard/private.key
sudo cat /etc/wireguard/private.key | wg pubkey | sudo tee /etc/wireguard/public.key

直接在服务器上生成客户端密钥对。peer_private.key 的内容需要填在客户端，peer_public.key 的内容需要填在服务器端。

wg genkey | sudo tee /etc/wireguard/peer_private.key
sudo chmod go= /etc/wireguard/peer_private.key
sudo cat /etc/wireguard/peer_private.key | wg pubkey | sudo tee /etc/wireguard/peer_public.key

配置 WireGuard¶

sudo vim /etc/wireguard/wg0.conf

在文件中添加以下内容：

[Interface]
PrivateKey = <server-private-key>
Address = 10.8.0.1/24
ListenPort = 51820
SaveConfig = true

PostUp = iptables -t nat -A POSTROUTING -o ens5 -j MASQUERADE
PostDown = iptables -t nat -D POSTROUTING -o ens5 -j MASQUERADE

# 客户端
[Peer]
PublicKey = <客户端公钥>  # 粘贴 /etc/wireguard/peer_public.key 内容
AllowedIPs = 10.8.0.2/32  # 分配固定IP

注意这里的网口是 ens5，而不是 eth0。到底是哪个网口，可以用 ip addr 命令查看。在 AWS EC2 Ubuntu 26.04 上是 ens5。

启用 IP 转发¶

# 1. 建一个独立 drop-in 文件，99- 前缀保证最后加载、不被覆盖
echo 'net.ipv4.ip_forward = 1' | sudo tee /etc/sysctl.d/99-ip-forward.conf

# 2. 立即生效（比 sysctl -p 更全，会扫整个 sysctl.d）
sudo sysctl --system

# 3. 验证
cat /proc/sys/net/ipv4/ip_forward   # 应返回 1
sysctl net.ipv4.ip_forward

IPv6 如果需要一并转，/etc/sysctl.d/99-ip-forward.conf 再加一行 net.ipv6.conf.all.forwarding = 1。再运行 sudo sysctl --system。

启动 WireGuard 服务器¶

sudo systemctl enable wg-quick@wg0
sudo systemctl start wg-quick@wg0

客户端操作¶

安装 WireGuard 命令行工具¶

brew install wireguard-tools

配置 wireguard-tools¶

# 创建文件夹
sudo mkdir /etc/wireguard
sudo chmod 777 /etc/wireguard

cd /etc/wireguard
sudo vim /etc/wireguard/wg0.conf

在 wg0.conf 中粘贴如下内容：

[Interface]
PrivateKey = <peer-private-key>     # 客户端私钥，在服务器上生成的 /etc/wireguard/peer_private.key 的内容
Address = 10.8.0.2/32
DNS = 8.8.8.8, 1.1.1.1

[Peer]
PublicKey = <server-public-key>     # 服务器公钥，在服务器上生成的 /etc/wireguard/public.key 的内容
Endpoint = 47.129.31.109:51820      # 47.129.31.109 是服务器公网 IP，替换成你的值
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25

连接 WireGuard 服务器¶

sudo wg-quick up wg0

WireGuard 图形界面¶

由于 AppStore 上的 WireGuard 客户端，只有美国区账户才能下载。我们可以从 Github 上下载 WireGuard 客户端。

添加客户端的步骤，可参考命令行方式。

错误诊断¶

在服务器上运行 sudo wg show wg0 检查是否有 latest handshake 和 transfer 包计数。

ubuntu@ip-172-31-31-207:~$ sudo wg show wg0
interface: wg0
  public key: <server-public-key>
  private key: (hidden)
  listening port: 51820

peer: <peer-public-key>
  endpoint: 112.48.5.71:2117
  allowed ips: 10.8.0.2/32
  latest handshake: 44 seconds ago
  transfer: 20.68 MiB received, 217.36 MiB sent

运营商屏蔽接口¶

51820 端口可能会被运动商屏蔽掉。现象就是，客户端发送握手消息，但收不到任何应答。服务器收到握手消息后，应答无法送达客户端。这个问题的解决办法，就是把 51820 端口换掉，比如换成 51822 端口即可。

  1. 停止 WireGuard 服务 sudo systemctl stop wg-quick@wg0
  2. 修改端口 sudo vim /etc/wireguard/wg0.conf
  3. 启动 WireGuard 服务 sudo systemctl start wg-quick@wg0
  4. 确认是否生效 sudo wg show wg0

可以直接保存下面的脚本为 wgp.sh，每次要修改端口时，运行 ./wgp.sh 51823 即可：

#!/usr/bin/env bash

NEW_PORT="$1"
CONF="/etc/wireguard/wg0.conf"

sudo systemctl stop wg-quick@wg0
sudo sed -i -E "0,/^ListenPort[[:space:]]*=.*/s//ListenPort = ${NEW_PORT}/" "$CONF"
sudo systemctl start wg-quick@wg0
sudo wg show wg0

NAT 转发规则错误¶

有 handshake，服务器收到很多数据（38.43 KB），但发送数据很少（188 B）。

ubuntu@ip-172-31-38-8:~$ sudo wg show wg0
interface: wg0
  public key: S1oG9/4nSRlmknlCPEfsjTX450XgI4jZGD0yBiHaaUY=
  private key: (hidden)
  listening port: 51820

peer: DLa6XAlz63+xGlr8IqqFi5k+3z8qR+kNZjb+YRPsjEE=
  endpoint: 112.48.5.96:24964
  allowed ips: 10.8.0.2/32
  latest handshake: 41 seconds ago
  transfer: 38.43 KiB received, 188 B sent

WireGuard 上网需要 MASQUERADE 伪装。我们直接添加规则。

# 查看转发规则
sudo iptables -t nat -L -n
# 有类似下面的输出，如果没有，说明转发规则有问题，需要手动添加
Chain POSTROUTING
MASQUERADE  all  --  10.8.0.0/24       anywhere

# 先查看外网网卡
ip route show default
# 输出如下，说明外网网卡是 ens5
default via 172.31.32.1 dev ens5 proto dhcp src 172.31.38.8 metric 100
# 添加转发规则，然后客户端生连即可
sudo iptables -t nat -A POSTROUTING -s 10.8.0.0/24 -o ens5 -j MASQUERADE

根本原因，可能是因为 /etc/wireguard/wg0.conf 里的端口转发规则，使用了错误的网口。请用 ip addr 检查真实的网口，然后把下面命令的 ens5 改成正确的网口。

[Interface]
PrivateKey = <server-private-key>
Address = 10.8.0.1/24
ListenPort = 51820
SaveConfig = true

PostUp = iptables -t nat -A POSTROUTING -o ens5 -j MASQUERADE
PostDown = iptables -t nat -D POSTROUTING -o ens5 -j MASQUERADE

# 客户端
[Peer]
PublicKey = <客户端公钥>  # 粘贴 /etc/wireguard/peer_public.key 内容
AllowedIPs = 10.8.0.2/32  # 分配固定IP
