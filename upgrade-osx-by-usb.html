从 U 盘安装 MacOS Big Sur 操作系统

写在前面¶

自己用的 Macbook Pro 是 2014 mid 版本，已经是老爷机了。最近速度越来越慢，升级到 MacOS Big Sur 后，更慢了，开机时间超过 1 分钟。一怒之下，备份了重要数据，准备抹掉全部硬盘，重新安装系统。

一入候门深似海。本文记录花了将近 2 天时间才完成重装的过程，以及那些踩过的坑。

方法概览¶

如何重新安装 macOS，苹果官方技术支持文档是最权威的。但这篇文档有个很容易误解的地方：

默认情况下，macOS 恢复功能会安装 Mac 上之前安装的最新版 macOS。

这句话的前提是，你没有抹掉整个硬盘。如果你抹掉了整个硬盘，那么 Mac 将无法安装任何 macOS，只能通过网络安装机器出厂时的版本。比如，我的是 2014 mid 款，只能安装 Yosemite 版本。好不容易花了几个小时，从网络下载 Yosemite 并安装完成，更坑的问题出现了：Yosemite 版本太老，无法登录 AppStore，这样就无法升级到更高版本的 macOS。

到了这一步，真是欲哭无泪，整个人都变得焦躁起来了。所幸，最后还是从苹果官方网站上找到了救命稻草。如何创建可引导的 macOS 安装器 文档里，有个链接，可以直接下载 OS X El Capitan 版本，不需要通过 AppStore 下载。这样，就绕过了无法登录 AppStore 的问题。

最后的流程，变成：

  1. 在 Yosemite 上，绕过 AppStore 下载 OS X El Capitan 版本安装包。
  2. 在 Yosemite 上，制作 OS X El Capitan 的 U 盘启动盘。其实这一步可以省掉，直接在 Yosemite 上打开 OS X El Capitan 安装包升级即可。
  3. 按照 如何创建可引导的 macOS 安装器 文档里描述的方法，从 U 盘启动安装 OS X El Capitan 版本。

需要注意，步骤 2 需要很长时间，可能几个小时。其实它就是把一个 6G 左右的文件拷到 U 盘上，不知道为什么要那么久。耐心等待就好。如果关心进度，可以使用 Finder 打开 U 盘根目录，检查里面的 Install OS X El Capitan.app 的文件，它的尺寸需要和 Application 目录下同名文件一样大。这个文件增加速度非常慢，我一度怀疑是我买到了假的 U 盘。

安装完 OS X El Capitan 版本，就解决了无法登录 AppStore 问题。这样就可以直接通过 AppStore 在线升级到 MacOS Big Sur 版本了。

在《禅和摩托车维修艺术》一书中，作者从摩托车维修过程中，悟到了非常深刻的哲学道理。电脑维修也差不多，需要保持内心平静，慢慢地发现电脑维修过程的“良质”，找到解决方案。

踩过的坑¶

踩过的坑，总结起来，有几个：

  1. 抹掉硬盘后，只能从网络安装，且只能安装电脑出厂时的版本。需要好几个小时。
  2. 安装太老的版本，导致无法登录 AppStore，无法升级系统。
  3. 制作 MacOS USB 安装盘，过程非常久，久到怀疑人生。可能要几个小时。
  4. 在 OS X El Capitan 下，通过 AppStore 下载下来的 MacOS Big Sur 版本只有 27MB，无法制作 U 盘启动盘。必须是在 MacOS Big Sur 版本下，再次通过 AppStore 下载 Big Sur 版本，才能制作成 U 盘安装盘。

第 4 点也是很坑。相当于，我要升级到 Big Sur 后，再下载 Big Sur，再制作 U 盘安装盘。然后再抹掉整个硬盘，重新安装 Big Sur。也许，你会有疑问？为什么这么麻烦，系统不是已经是 Big Sur 的了吗？我的述求是，从头安装一个干净的 Big Sur，而不是从老版本升级上来的。我想验证一下，这种情况下是不是开机会变得更快。之前升级上来后，系统开机变得非常慢。

我映像非常深刻的是，当初刚拿到手 Macbook Pro 机器时，当时机器上安装的是 Yosemite，开机速度非常快，10 秒内就可以进桌面。不记得什么时候开始，开机速度越来越慢。这次升级，重新感受了一下这个过程。Yosemite 下，还是 10 秒开机到桌面，非常平滑。一旦升级到 OS X El Capitan，开机就需要 30 秒左右。一下子就变慢了很多。不知道是苹果故意为之，还是确实软件变慢了，还是优化不够，不得而知。

最终验证的结果，还是有稍微差别：

  1. 从 Yosemite 一路升级到 Big Sur，从按下电源键开机，到进入桌面，大概需要 42 秒。
  2. 直接抹掉硬盘，从 U 盘安装 Big Sur，从按下电源键开机，到进入桌面，大概需要 36 秒。
