融头拍卖外挂

前言¶

各个拍卖平台外挂项目数据分析。

融头拍卖¶

融头拍卖平台的数据分析，通过 http://mob.i-ling.com 访问。

注册及登录¶

直接通过手机号码和短信验证码注册及登录。不需要邮箱，也不需要密码。

请求短信验证码¶

curl 'https://rt.i-ling.com/v1/public/account/login/sms' \
  -H 'authority: rt.i-ling.com' \
  -H 'pragma: no-cache' \
  -H 'cache-control: no-cache' \
  -H 'user-agent: Mozilla/5.0 (iPhone; CPU iPhone OS 13_2_3 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/13.0.3 Mobile/15E148 Safari/604.1' \
  -H 'content-type: application/json;charset=UTF-8' \
  -H 'accept: */*' \
  -H 'origin: http://mob.i-ling.com' \
  -H 'sec-fetch-site: cross-site' \
  -H 'sec-fetch-mode: cors' \
  -H 'sec-fetch-dest: empty' \
  -H 'referer: http://mob.i-ling.com/' \
  -H 'accept-language: zh-CN,zh;q=0.9,en;q=0.8' \
  --data-binary '{"phone_number":"13859901820"}' \
  --compressed

出价¶

商品页面链接¶

http://mob.i-ling.com/#/pages/goodsDetails/goodsDetails?id=201007960620

获取当前出价信息¶

curl 'https://rt.i-ling.com/v1/public/auction/201007960620/bidding' \
  -H 'authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9.eyJpc3MiOiJydC5pLWxpbmcuY29tIiwiaWF0IjoxNjAyOTgxNTA3LCJuYmYiOjE2MDI5ODE1MDcsImV4cCI6MTYyNTIwMzcyOSwidXNlciI6eyJpZCI6OTQ5MjcyOTAyMDQsInRva2VuX3NhZmVfaWF0IjoxNjAyOTgwMDQ1fX0.huWM_NuHRjxYWcH5r_BhDUoLcznT8a5Hq_F3UeU-QNfZfrNNtqD6rlgrmpKmqEL0Q2JKw1ulw9GaTM7MmEIJY1uPUelvrD4kteJK3XaA3hfs5Ntbm_82jID-RJbq3Fr3cFR_uTlN185ioSu9UOIJN9BKRcqgoK5jShkkpKh9CSpIyjFLUzPeEFu3QoN-gpV8hpfvnZT2Fl3Aip0p9cUQ--EbNgQ2fSAhkWaajUqIdD6NAYIrhCTT7X3sRQeQnQO8ygNQRrSFnqK1Q3wGNGcRj1j0eV4YSIcUjWZ1CFx2J4iKqtc6fRgF7C3vNNn_eBBLElYLatww6UkrYvUk846G-w' \

{"data":[{"multiple":1,"created_at":"2020-10-08 11:03:45","user":{"avatar":"https:\/\/img.alicdn.com\/tfs\/TB1L6tBXQyWBuNjy0FpXXassXXa-80-80.png","level":0,"hide_nickname":"\u6b22***\u597d"}}]}

其中 multiple 表示出价 “手” 数，1 表示有人出了 1 “手”的价格。什么是 “手” 呢？手，其实是卖家在上架拍品时设置的，每次出价上浮的金额。比如，卖家可以上架一个拍品，底价为 0，每次出价上浮 10 元。那么，如果当前有人出了 1 手，就是 10 元，如果有人直接加 2 手，就是 30 元。
