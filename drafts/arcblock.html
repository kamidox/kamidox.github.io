应聘 ArcBlock 中国研发中心全栈工程师

欣闻 ArcBlock 中国研发中心招聘可远程工作的全栈工程师。自觉大部分能力满足要求，是故有此自荐信。

本人是陈天的微信公众号 “程序人生” 的忠实读者，故很早就知道 ArcBlock，也非常佩服天哥勇敢地从稳定的 tubi 踏入未知的 ArcBlock 的勇气。

我是谁？

黄永昌，出生于 1982 年。2000 年毕业于厦门大学自动化系。是个老程序员，十几年来，一直从事开发及开发管理工作。具体职业生涯可参阅简历。

为什么说我适合这个工作？

  • 有全栈工程师工作经验。业余时间，作为全栈工程师完成了一些简单的业余作品。小程序 “51经典电影” 和 “51读书”（微信搜索可达）。独立开发前后端程序。前端使用腾讯开源的 weui，后端通过 Django 实现 REST API 给前端提供接口。
  • 技术栈全面，学习能力强，热爱学习新技术，常常在学习新技术过程中达到“心流”状态。喜欢和聪明人一起工作，追求科学的开发流程和方法。厌倦了“伪”技术公司通过人肉黑盒测试来保证软件质量的方法。
  • 精通 C 语言，长期使用 C 进行嵌入式以及 Linux 下的应用开发。sfox 是一个 2007 年左右的作品，使用 C 语言从头实现 wap 浏览器、彩信和电子邮件客户端。可以方便地在不同的嵌入式平台上移植，对平台的依赖仅限于文件系统读写，socket 网络接口等最基本的基础设施。自己实现适合在功能机上（低内存，CPU 性能低）运行的各种基础组件，包括 xml/wml/html 页面解析，渲染；http/https/mms/pop3/smtp 网络通信协议栈；一个轻量级的 UI 引擎等。在当时，可以在占用不到 2MB 内存的情况下，打开 200KB+ 的新浪主页。当然，后来由于智能手机及移动互联网的高速发展，这种在当时看来有点技术含量（内存小，跨平台）应用，实际上没有任何前景。但个人通过这样的项目，获得了非常大的成长。
  • 熟悉 JavaScript，熟悉微信小程序的开发。熟悉 React，学习 React 时作为玩票作品，通过 Hacker News API，使用 React 仿制了一个 Hacker News 客户端。了解 Vue.js，目前暂无完整作品，更多地是去了解不同的框架之间的异同点及优缺点，以及对一些特定问题的不同解决方法。此外，本职工作中曾使用 qooxdoo 开发过前端程序（一个楼宇对讲系统的上位机软件）。
  • 熟悉 Python 语言及相关常用框架和基础库。经常用来开发一些提高开发效率的脚本，如使用 Python 结合 unity/cmock 开发适合嵌入式平台上使用的单元测试框架。此外，业余使用 Python 开发过微信小程序后端程序及公众号后端程序。
  • 自学过机器学习相关知识。完成 Coursera 上 Andrew Ng 的机器学习课程，并获得证书。出版过一本介绍 scikit-learn 机器学习入门的书。当然，自己的水平远达不到出书的水平，这里面有很多好玩的故事。但通过出书，倒逼自己深入学习了很多机器学习相关的知识。在机器学习领域暂无完整的作品，最好的成绩是在 Kaggle 上获得了一次铜牌。
  • 了解过 Go/Dart(Flutter) 等语言。暂无完整作品，只完成部分 exercism 练习。
  • 良好的英语听说读写能力。可接受全英文工作环境，可接受全英文面试。可以自由地使用英文进行技术交流和技术演讲。有跨国公司合作交流经验。
  • 了解区块链的概念，了解比特币上使用的 Proof Of Work 算法。曾经走马观花地阅读过 bitcoinj 的源码。
  • 有 Android Native App 开发经验。开发过 Android 手机，维护过 Android 手机上的 Launcher，Contacts 等应用。在工作中，参与过楼宇对讲 Android App 的开发，主要是使用 liblinphone 实现远程视频通话。
  • 良好的结构化思维能力，良好的表达能力，写作能力强。
  • 出版过《scikit-learn机器学习常用算法原理及编程实战》
  • 出版过《scratch 少儿编程魔法课堂》
  • 麦子学院视频教程《Pandas教程》
  • 麦子学院视频教程《Python爬虫基础》
  • Markdown 铁粉。出版过的两本书，都是通过 markdown 编写，再通过 kitabu 转换为 word/pdf 文档，再发给出版社排版。这篇自荐信，也是通过 markdown 编写，通过 pelican/ghp-import 部署在 github pages 上。
  • 高度自律：持续跑步 6 年多，每年跑量在 1000 公里以上。
  • 通过公众号 “程序人生” 了解一陈天，进而了解了 ArcBlock。相信这是一个由一群聪明的人组成的优秀的研发团队。高度认同陈天及 ArcBlock 的开发流程，做事方式。

针对这个职位，我有哪些不足？

  • 缺少互联网公司工作经验，大部分全栈作品都是个人玩票性质的作品。对高可用，可伸缩的互联网服务只停留在理论水平，实践经验不足。这是最大的硬伤。
  • 解决方案：如果有幸加入 ArcBlock，可通过学习现有框架，阅读现有源码，快速补齐这方面的短板。
  • 对区块链完整的知识图谱及应用场景缺乏全景视图。
  • 解决方案：如果有幸加入 ArcBlock，可以通过进一步学习补齐这方面的短板。此外，后续通过接触 ArcBlock 的客户和用户，进一步了解区块链的应用场景。当然，更优雅的方式，是先自己补齐区块链相关的知识图谱，研究 ArcBlock 现有产品。但由于时间紧迫，只能先通过自荐信抓住这个机会，后续再来补。
