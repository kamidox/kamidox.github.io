Docker 笔记¶

Docker 官方文档¶

https://docs.docker.com/docker-for-mac/

用例驱动的简化版 manual: https://www.freecodecamp.org/news/docker-image-guide-how-to-remove-and-delete-docker-images-stop-containers-and-remove-all-volumes/#:~:text=Docker%20Image%20Guide%3A%20How%20to%20Delete%20Docker%20Images%2C,10%20Remove%20a%20container.%20…%20More%20items…%20

ubuntu 下安装 docker¶

https://docs.docker.com/engine/install/ubuntu/#install-from-a-package

Docker 下载加速¶

把下列镜像加入到 docker daemon 配置文件 ~/.docker/daemon.json 中。如：

{
  "registry-mirrors" : [
    "https://docker.mirrors.ustc.edu.cn",
    "https://registry.docker-cn.com"
  ],
  "debug" : true,
  "experimental" : false
}

进入正在运行的 Docker Container Shell¶

先查询正在运行的 container：

$ docker ps
CONTAINER ID        IMAGE               COMMAND                  CREATED             STATUS              PORTS                NAMES
e5c0493ee155        nginx               "nginx -g 'daemon of…"   2 hours ago         Up 20 minutes       0.0.0.0:80->80/tcp   nginx

然后通过 docker exec 命令进入 container：

$ docker exec -it nginx /bin/bash
root@e5c0493ee155:/#

可以通过 CONTAINER ID 或 NAMES 字段的值来指定要进入的 container。

查看 container 文件夹大小¶

进入 container，在根目录运行 du -h -d 1 。

查看 container 己安装的软件包¶

进入 container，运行 dpkg -l

给己存在的 container 挂载文件系统¶

假设我们已经有一个已经存在的 ubuntu 20.04 的 container，并且在这个 container 里，我们已经安装了很多我们需要的软件。现在想给这个 container 挂载一个新的文件系统，此时如果通过命令 sudo docker run -v $PWD:/weapp --name=weapp ubuntu:20.04 运行，会产生一个新的 container 并且那些软件需要重新安装。

一个可行的方法是，把已经装好软件的这个 container commit 成一个新的 image，然后挂载一个新的文件系统，来运行这个新的 image 。

$ docker container ps -a
CONTAINER ID        IMAGE                             COMMAND                  CREATED             STATUS                       PORTS                    NAMES
8e124aa75493        ubuntu:20.04                      "/bin/bash"              8 hours ago         Up 24 minutes                                         ubuntu
6b7ac5b17190        mitchallen/pi-cross-compile       "/bin/bash"              8 months ago        Exited (255) 9 hours ago                              pi-cc
f06db99dd0c5        nginx                             "nginx -g 'daemon of…"   10 months ago       Exited (0) 10 months ago                              nginx-php

$ docker commit 8e124aa75493 weapp:1.0
sha256:dc31132b7a5216d468bd1b405d9fc212ddca9811ab18a1cfa3280cc02c39fbe8

$ docker images
REPOSITORY                    TAG                 IMAGE ID            CREATED             SIZE
weapp                         1.0                 dc31132b7a52        20 seconds ago      545MB
ubuntu                        20.04               9140108b62dc        5 days ago          72.9MB

可以看到，我们创建的 weapp 的 image 已经生成了。然后，通过下面的命令即可运行这个 image 。

$ docker run -ti -v $PWD:/weapp --name=weappserver weapp:1.0 /bin/bash

@see: https://stackoverflow.com/questions/28302178/how-can-i-add-a-volume-to-an-existing-docker-container

删除某个 image¶

先使用 docker images 查看所有己下载的 image。然后使用 docker image rm xxx -f 来删除某个 image，其中 xxx 是 image id。

端口映射¶

把 container 里的服务端口映射到外部，可以使用 -p 参数。如 docker run -p 8080:80 nginx:latest。

把 django 应用容器化的示例¶

最重要的原则，是在容器里把所有的应用手动配置一遍，确保服务器运行起来，然后再编写 Dockerfile。

https://medium.com/swlh/dockerize-a-django-application-68e1b5d85d76

使用 docker 运行 letsencrypt¶

https://certbot.eff.org/docs/install.html#running-with-docker

sudo docker run -it --rm --name certbot \
            -v "/etc/letsencrypt:/etc/letsencrypt" \
            -v "/var/lib/letsencrypt:/var/lib/letsencrypt" \
            certbot/certbot certonly

运行最小的 linux 系统¶

alpine 总共才 5MB 左右。通过下面的命令，运行 alpine 3.10 版本，并且进入 alpine shell 命令行。

$ docker run -dit --name=alpine alpine:3.10
$ docker exec -it alpine /bin/sh

拷贝文件¶

拷贝文件或文件夹。从容器拷贝到主机。

$ docker cp container-name:/etc/nginx/conf.d ./

从主机拷贝到容器。

$ docker cp  ./conf.d container-name:/etc/nginx/conf.d
