Docker 笔记

Docker 笔记

Docker 官方文档

https://docs.docker.com/docker-for-mac/

Docker 下载加速

把下列镜像加入到 docker daemon 配置文件 ~/.docker/daemon.json 中。如：

{
  "registry-mirrors" : [
    "https://docker.mirrors.ustc.edu.cn",
    "https://registry.docker-cn.com"
  ],
  "debug" : true,
  "experimental" : false
}

进入正在运行的 Docker Container Shell

先查询正在运行的 container：

$ docker ps
CONTAINER ID        IMAGE               COMMAND                  CREATED             STATUS              PORTS                NAMES
e5c0493ee155        nginx               "nginx -g 'daemon of…"   2 hours ago         Up 20 minutes       0.0.0.0:80->80/tcp   nginx

然后通过 docker exec 命令进入 container：

$ docker exec -it nginx /bin/bash
root@e5c0493ee155:/#

可以通过 CONTAINER ID 或 NAMES 字段的值来指定要进入的 container。

查看 container 文件夹大小

进入 container，在根目录运行 du -h -d 1 。

查看 container 己安装的软件包

进入 container，运行 dpkg -l

运行最小的 linux 系统

alpine 总共才 5MB 左右。通过下面的命令，运行 alpine 3.10 版本，并且进入 alpine shell 命令行。

$ docker run -dit --name=alpine alpine:3.10
$ docker exec -it alpine /bin/sh
