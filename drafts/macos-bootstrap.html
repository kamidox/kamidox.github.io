从头配置 MacOS 操作系统

安装软件¶

brew¶

https://brew.sh

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"

注意：

  1. 安装前，需要先安装 xcode，并且需要通过 xcode-select --install 安装 xcode 命令行工具。
  2. 上述命令可能被 GFW 屏蔽。有可能需要通过 VPN 才能安装。

使用 aliyun 镜像：

# 替换brew.git:
cd "$(brew --repo)"
git remote set-url origin https://mirrors.aliyun.com/homebrew/brew.git
# 替换homebrew-core.git:
cd "$(brew --repo)/Library/Taps/homebrew/homebrew-core"
git remote set-url origin https://mirrors.aliyun.com/homebrew/homebrew-core.git
# 应用生效
brew update
# 替换homebrew-bottles:
echo 'export HOMEBREW_BOTTLE_DOMAIN=https://mirrors.aliyun.com/homebrew/homebrew-bottles' >> ~/.zshrc
source ~/.zshrc

使用 brew update -v -f 强制更新源。安装常用软件 brew install vim autojump。

Spectacle¶

https://www.spectacleapp.com

应用已经不再维护了，如果下载慢，可以上百度网盘 tools/mac 目录下载。

MacOS 优化¶

https://github.com/kamidox/dotfiles

  1. 运行 cd ~/dotfiles && ./bootstrap.sh 拷贝所有的配置文件到主目录。
  2. 运行 cd ~ && ./.macos 文件进行设置优化。

oh-my-zsh¶

https://ohmyz.sh

sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

安装 oh-my-zsh 插件 autojump: brew install autojump。

其他插件：https://www.jianshu.com/p/bd9ea233f933

Pelican¶

pip3 install "pelican[markdown]"
