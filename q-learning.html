Q-Learning 算法原理及示例

一、直觉：Q-Learning 到底在干嘛？

核心思想一句话

Q-Learning 是在学一张表（Q-Table），表里每个格子回答一个问题： “在状态 s 下，采取动作 a，我预期未来总共能拿多少分？”

这个”预期总分”就叫 Q 值（Quality Value）。

一个生活类比：选餐厅

状态（你在哪条街） 动作（去哪家店） Q 值（预期体验分）
商业街 去火锅店 8.5
商业街 去沙拉店 6.0
居民区 去火锅店 5.0
居民区 去沙拉店 9.0

你每去一次，根据实际体验更新表格里的分数。去多了，表格越来越准，你就知道”在哪条街该去哪家店”。

为什么叫”Q”？

Q = Quality（质量），就是”这个动作的质量分”。

二、数学：Q-Learning 更新公式

Q 表结构 

Q[state][action] = 预期未来累计奖励

核心更新公式（Bellman Equation）

$$ Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right] $$

拆开看每个符号：

符号 含义
\(Q(s,a)\) 当前 Q 表中 (s,a) 的值
\(\alpha\) 学习率（0~1），控制更新幅度
\(r\) 执行动作后立即拿到的奖励
\(\gamma\) 折扣因子（0~1），未来奖励的权重
\(\max_{a'} Q(s',a')\) 下一个状态 \(s'\) 中最好的动作的 Q 值
\(r + \gamma \max Q(s',a')\) TD 目标（Target）——“我期望拿到的总分”
\([]\) 里的整体 TD 误差（TD Error）——“预期和实际的差距”

直觉理解更新公式 

新 Q = 旧 Q + 学习率 × (实际拿到的 + 未来最好的 − 旧 Q)

就像你考试估分：你估了 80 分（旧 Q），结果考了 90 分（TD 目标），下次估分就往 90 靠一点。

ε-贪心（ε-Greedy）探索策略

策略 做什么 概率
探索（Explore） 随机选动作 ε（比如 10%）
利用（Exploit） 选 Q 值最高的动作 1-ε（比如 90%）

纯随机永远学不会，纯贪心永远困在局部最优。ε-贪心 = 两者平衡。

三、完整 Python 3.12 实现（Taxi-v4）

环境说明：Taxi-v4

  • 状态：出租车位置 + 乘客位置 + 目的地（共 500 种状态）
  • 动作：向南/北/东/西/接客/放客（6 种）
  • 目标：最短时间内把乘客送到目的地
  • 奖励：每步 -1，非法动作 -10，成功 +20

完整代码（直接复制运行）

以下代码，在 Python 3.12 + Gymnasium 1.3.0 验证通过。

"""
Q-Learning on Taxi-v4
Python 3.12 + Gymnasium 1.3.0
"""

import gymnasium as gym
import numpy as np
import random
from collections import defaultdict


# ==================== 超参数 ====================
ALPHA = 0.1          # 学习率 α
GAMMA = 0.99         # 折扣因子 γ
EPSILON = 1.0        # 初始探索率 ε
EPSILON_DECAY = 0.995  # ε 衰减
EPSILON_MIN = 0.01   # ε 最小值
EPISODES = 2000      # 训练回合数
MAX_STEPS = 200      # 每回合最大步数


# ==================== 初始化 ====================
env = gym.make("Taxi-v4")

# Q 表：用 defaultdict 代替 np.zeros，避免状态空间全分配
Q = defaultdict(lambda: np.zeros(env.action_space.n))

episode_rewards = []
episode_steps = []


# ==================== ε-贪心策略 ====================
def epsilon_greedy(state, epsilon):
    """ε-贪心：以 ε 概率随机探索，否则选 Q 值最大的动作"""
    if random.random() < epsilon:
        return env.action_space.sample()  # 探索
    else:
        return int(np.argmax(Q[state]))   # 利用


# ==================== 训练循环 ====================
for episode in range(EPISODES):
    state, _ = env.reset()
    total_reward = 0
    steps = 0

    for step in range(MAX_STEPS):
        # 1. 选动作
        action = epsilon_greedy(state, EPSILON)

        # 2. 执行动作
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated

        # 3. 更新 Q 表（核心！）
        # Q(s,a) ← Q(s,a) + α [r + γ max Q(s',a') - Q(s,a)]
        old_q = Q[state][action]
        max_next_q = np.max(Q[next_state])
        td_target = reward + GAMMA * max_next_q
        Q[state][action] = old_q + ALPHA * (td_target - old_q)

        # 4. 转移
        state = next_state
        total_reward += reward
        steps += 1

        if done:
            break

    # ε 衰减
    EPSILON = max(EPSILON_MIN, EPSILON * EPSILON_DECAY)

    episode_rewards.append(total_reward)
    episode_steps.append(steps)

    # 每 100 回合打印一次
    if (episode + 1) % 100 == 0:
        avg_reward = np.mean(episode_rewards[-100:])
        avg_steps = np.mean(episode_steps[-100:])
        print(f"Episode {episode+1:4d} | "
              f"Avg Reward: {avg_reward:7.1f} | "
              f"Avg Steps: {avg_steps:5.1f} | "
              f"Epsilon: {EPSILON:.3f}")


env.close()
print("\n✅ 训练完成！")


# ==================== 测试（无探索） ====================
print("\n🎮 开始测试...")
test_env = gym.make("Taxi-v4", render_mode="human")

for test_ep in range(5):
    state, _ = test_env.reset()
    total_reward = 0
    done = False

    print(f"\n--- Test Episode {test_ep + 1} ---")
    while not done:
        action = int(np.argmax(Q[state]))  # 纯贪心，不探索
        state, reward, terminated, truncated, _ = test_env.step(action)
        total_reward += reward
        done = terminated or truncated

    print(f"Total Reward: {total_reward}")

test_env.close()

Episode  200 | Avg Reward:  -180.5 | Avg Steps: 180.0 | Epsilon: 0.366

...

  • 前期：ε 大，随机探索，reward 很低（甚至 -200 封顶）
  • 中期：开始学到”接客→送到目的地”的路径，reward 转正
  • 后期：ε 很小，几乎纯贪心，reward 稳定在 +8~+12（说明 20 分奖励 - 约 12 步 × 1 = 8）

五、Q-Learning 的优缺点

优点 缺点
原理简单，代码短 只能处理离散状态/动作
理论保证收敛（条件满足时） 状态空间大了 Q 表存不下
不需要环境模型（model-free） 收敛慢

状态空间大了怎么办？ → 用 Deep Q-Network (DQN)，用神经网络代替 Q 表。这就是下一阶段要学的。

六、关键概念速查

概念 一句话
Q-Table 状态×动作的二维表，存预期总分
TD Target \(r + \gamma \max Q(s',a')\)，当前这一步的”正确答案”
TD Error Target − 旧 Q，误差
ε-Greedy 平衡探索和利用
Off-policy 用别人的经验（比如随机策略）也能学
