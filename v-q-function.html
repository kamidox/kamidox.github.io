强化学习中的值函数与 Q 函数

一、总览：它们解决什么问题？

在强化学习（RL）中，智能体（Agent）通过与环境交互来学习“在某个状态下，做什么动作最好”。

值函数（Value Function）和 Q 函数（Action-Value Function / Q-function）就是用来量化“好”的程度的数学工具，是 RL 决策的核心依据。

二、马尔可夫决策过程（MDP）基础

在深入之前，先明确符号。一个 MDP 由五元组 \((S, A, P, R, \gamma)\) 定义：

符号 含义
\(S\) 状态空间（State space）
\(A\) 动作空间（Action space）
\(P(s'\|s,a)\) 状态转移概率：在状态 \(s\) 执行动作 \(a\) 后转移到 \(s'\) 的概率
\(R(s,a,s')\) 或 \(R(s,a)\) 奖励函数：执行动作后获得的即时奖励
\(\gamma \in [0,1]\) 折扣因子：权衡即时奖励与未来奖励的重要性

智能体的目标是最大化累积折扣奖励（Return）：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

三、值函数（Value Function，V 函数）

1. 定义

状态值函数 \(V^\pi(s)\) 表示：在策略 \(\pi\)（即从状态到动作的映射）下，从状态 \(s\) 出发，未来能获得的期望累积折扣奖励：

$$V^\pi(s) = \mathbb{E}_\pi \left[ G_t \mid S_t = s \right] = \mathbb{E}_\pi \left[ \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \;\middle|\; S_t = s \right]$$

2. 核心物理含义

  • \(V^\pi(s)\) 衡量的是“这个状态本身有多好”（在策略 \(\pi\) 下）。
  • 它是对状态长期价值的期望评估，考虑了从该状态出发后所有可能的动作序列和状态转移。
  • 值越高，说明从该状态出发，未来能获得的奖励越多。

3. 贝尔曼方程（Bellman Equation）

值函数满足一个递归关系，这是 RL 算法的理论基础：

$$V^\pi(s) = \sum_{a} \pi(a|s) \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V^\pi(s') \right]$$

含义：当前状态的值 = 执行策略 \(\pi\) 选择的动作后，获得的即时奖励 + 折扣后的下一状态值的期望。

直觉：值函数把“未来”压缩进了“现在”——你知道从 \(s'\) 出发平均能拿多少，所以 \(s\) 的价值就等于“当前这一步的奖励”加上“未来能拿到的平均价值”。

4. 最优值函数

最优状态值函数 \(V^*(s)\) 是所有策略中值最大的：

$$V^*(s) = \max_\pi V^\pi(s)$$

对应的最优策略 \(\pi^*\) 满足：

$$\pi^*(a|s) = \begin{cases} 1 & \text{if } a = \arg\max_a \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V^*(s') \right] \\ 0 & \text{otherwise} \end{cases}$$

四、Q 函数（Action-Value Function，Q 函数）

1. 定义

动作值函数 \(Q^\pi(s,a)\) 表示：在策略 \(\pi\) 下，从状态 \(s\) 出发先执行动作 \(a\)，之后继续遵循策略 \(\pi\)，未来能获得的期望累积折扣奖励：

$$Q^\pi(s,a) = \mathbb{E}_\pi \left[ G_t \mid S_t = s, A_t = a \right] = \mathbb{E}_\pi \left[ \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \;\middle|\; S_t = s, A_t = a \right]$$

2. 核心物理含义

  • \(Q^\pi(s,a)\) 衡量的是“在状态 \(s\) 下执行动作 \(a\) 有多好”（在策略 \(\pi\) 下）。
  • 它比 \(V\) 函数多了一个维度：同时评估状态和动作的组合。
  • 如果说 \(V(s)\) 是“这个位置好不好”，那 \(Q(s,a)\) 就是“在这个位置做这个动作好不好”。

3. 贝尔曼方程（Bellman Equation for Q）

$$Q^\pi(s,a) = \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s',a') \right]$$

含义：在 \((s,a)\) 处的 Q 值 = 即时奖励 + 折扣后的下一状态所有动作 Q 值的期望（按策略 \(\pi\) 加权）。

4. 最优 Q 函数

最优 Q 函数 \(Q^*(s,a)\) 满足：

$$Q^*(s,a) = \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma \max_{a'} Q^*(s',a') \right]$$

最优策略直接从 Q 函数读取：

$$\pi^*(s) = \arg\max_a Q^*(s,a)$$

这是 Q-learning 和 DQN 等算法的核心依据。

五、V 函数与 Q 函数的关系

1. 数学关系

在策略 \(\pi\) 下，两者可以相互转换：

$$V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)$$

即：状态值 = 在该状态下按策略选择各动作的 Q 值的期望。

反过来：

$$Q^\pi(s,a) = \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V^\pi(s') \right]$$

即：Q 值 = 即时奖励 + 折扣后的下一状态值的期望。

2. 对比表

输入 状态 \(s\) 状态-动作对 \((s,a)\)
输出 标量：该状态的长期价值 标量：该状态下执行该动作的长期价值
用途 评估状态好坏，用于基于策略的方法（如 Policy Gradient） 直接指导动作选择，用于基于值的方法（如 Q-learning, DQN）
最优策略获取 需要额外的模型（\(P\) 和 \(R\)）来算 \(\arg\max_a\) 直接 \(\arg\max_a Q(s,a)\) 即得最优动作

六、物理含义的深度理解

1. 从“势能”的角度

可以把 \(V(s)\) 想象成状态空间中的“势能面”：

  • 高值区域 = “好”的状态（容易获得高奖励）
  • 低值区域 = “差”的状态
  • 智能体的目标就是在势能面上“爬山”

Q 函数则像是从每个状态出发的“方向梯度”：

  • \(Q(s,a_1) > Q(s,a_2)\) 意味着在 \(s\) 处选择 \(a_1\) 比 \(a_2\) 更“上坡”

2. 从“信用分配”的角度

RL 的难点是信用分配问题：一个最终的成功（或失败）是由之前哪些动作导致的？

  • \(V(s)\) 把未来的所有奖励“回溯”分配到当前状态
  • \(Q(s,a)\) 更精细地把奖励分配到具体的动作上

这正是 Q-learning 能直接从经验中学习的原因：每次执行 \((s,a)\) 并观察到奖励 \(r\) 和下一状态 \(s'\)，就可以用 TD 误差更新：

$$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right]$$

这个公式的含义是：用“实际看到的奖励 + 下一状态的最大 Q 值”来修正对 \(Q(s,a)\) 的估计。

3. 从“规划”的角度

在 Model-Based RL 中，如果你知道环境模型 \(P\) 和 \(R\)，可以直接用值迭代（Value Iteration）：

$$V_{k+1}(s) = \max_a \sum_{s'} P(s'|s,a) \left[ R(s,a,s') + \gamma V_k(s') \right]$$

这本质上是在动态规划：从终态往回推，逐步计算出每个状态的最优值。

七、在机器人/自动驾驶中的具体意义

结合你熟悉的领域，这些概念的实际对应是：

RL 概念 机器人/自动驾驶对应
状态 \(s\) 机器人位姿、速度、传感器读数（激光雷达点云、相机图像）、环境地图
动作 \(a\) 控制指令：线速度、角速度、转向角、加速度
奖励 \(r\) 前进距离（正）、碰撞（负）、偏离车道（负）、平滑度（正）
\(V(s)\) “当前这个位姿和感知状态，后续能顺利完成任务的概率/期望收益”
\(Q(s,a)\) “在当前位姿下，给这个控制指令，后续能顺利完成任务的概率/期望收益”

在 sim2real 中，Q 函数（或近似的 Q 网络）学到的就是“在什么情况下做什么控制决策”的映射，这个映射是从仿真中大量试错后提炼出来的。

八、总结

要点 说明
值函数 \(V(s)\) 评估状态的长期价值，是“势能面”
Q 函数 \(Q(s,a)\) 评估状态-动作对的长期价值，是“方向梯度”
贝尔曼方程 递归关系，是 TD 学习、Q-learning、值迭代的理论基础
最优 Q 函数 直接给出最优策略：\(\pi^*(s) = \arg\max_a Q^*(s,a)\)
核心思想 把未来的累积奖励“压缩”成对当前状态/动作的标量评估，指导决策
